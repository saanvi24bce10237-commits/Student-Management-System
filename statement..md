Problem Statement — Student Management System

Managing student records manually can be time-consuming
and may lead to errors, data duplication, or difficulty
in finding and updating information. Therefore, there is
a need for a simple computerized system that can efficiently manage student details.

The Student Management System is developed using Python to provide an
easy way to add, view, search, update, and delete student records. The
system reduces manual effort and makes student information easier to organize and access.
