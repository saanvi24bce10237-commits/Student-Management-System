🎓 Student Management System

A simple and user-friendly Student Management System developed using Python. The project allows users to add, view, search, update, and delete student information.

📌 Project Description

The Student Management System is a Python-based application designed to manage student records efficiently. It provides an easy way to store and manage details such as student name, roll number, age, course, and marks.

The project is suitable for beginners and demonstrates important Python programming concepts such as variables, functions, conditional statements, loops, lists/dictionaries, and user input.

✨ Features

- ➕ Add new student records
- 👀 View all student records
- 🔍 Search for a student
- ✏️ Update student details
- 🗑️ Delete student records
- 📊 Store student marks and information
- ❌ Exit the application
- 🖥️ Simple and user-friendly interface

🛠️ Technologies Used

- Python 3
- Lists/Dictionaries – For storing student information

🧠 Python Concepts Used

- Variables
- Data types
- Functions
- "if-else" statements
- Loops
- Lists and dictionaries
- User input
- Exception handling
- Tkinter widgets and events

▶️ How to Run

1. Install Python

Make sure Python 3 is installed on your computer.

2. Clone the Repository

3. Open the Project Folder

cd Student-Management-System

4. Run the Program

python student_management.py

🎯 How It Works

1. Launch the application.
2. Select the required operation.

4. Add or modify the information.
5. Use the search option to find a particular student.
6. Update or delete records whenever required.
